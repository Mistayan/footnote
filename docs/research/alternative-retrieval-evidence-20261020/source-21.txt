For a fully managed experience, get started with ParadeDB
Cloud.
Get started locally with our Curlbash installer, Docker, or Postgres.app.
Curlbash
Docker
Postgres.app (macOS)
curl -fsSL https://paradedb.com/install.sh | sh
The Curlbash installer starts ParadeDB in Docker with persistent storage, prints your connection credentials, and opens a psql session. Save the generated password to connect from your application.To reconnect later, run:
docker exec -it paradedb psql -U postgres -d paradedb
docker run \
--name paradedb \
-e POSTGRES_USER=postgres \
-e POSTGRES_PASSWORD=mygoodpassword \
-e POSTGRES_DB=paradedb \
-v paradedb_data:/var/lib/postgresql/ \
-p 5432:5432 \
-d \
paradedb/paradedb:latest
Replace mygoodpassword with your chosen password and adjust the username and database name as needed. To connect, run:
docker exec -it paradedb psql -U postgres -d paradedb -W
These steps assume you have Postgres.app running PostgreSQL 18.
Download the pg_search installer from the Postgres.app extensions page and install it.
Connect to your database via psql, run SHOW config_file; to locate postgresql.conf, then add pg_search to shared_preload_libraries:
shared_preload_libraries = 'pg_search'
If other libraries are already listed, keep them and append pg_search to the comma-separated list. Stop and start the Postgres server to apply the change.Lastly, connect to your database via psql and enable ParadeDB:
CREATE EXTENSION pg_search CASCADE;
Postgres.app includes pgvector, which CASCADE enables automatically.
