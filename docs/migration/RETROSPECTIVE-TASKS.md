## Matched baseline proposal (frozen, not executed)

- Same explicitly pinned answering model, reasoning, prompt, corpus bytes/revisions and token ceilings in both arms.
- Filesystem baseline: local case-insensitive literal/regex filename/text search, stable path/line ordering, no semantic index or hidden recursive reading. At most **3 searches, first 20 spans per search**, **5 get reads**. Search previews cap at **500 characters/hit**; each get caps at **12,000 characters**; final answer cap **2,000 tokens**. Truncation and all activity logged.
- Indexed arm: agent-facing search/get with the same call/result/character caps. Source paths and expected quotes/rubrics are withheld from the answering agent unless present in the genuine request.
- Score final-answer correctness/completeness and applicable citation support against independently checked original sources; report abstention/unknown, wrong-version, proof sufficiency and cost separately. No top-one proxy or past assistant answer used as gold.
- Historical and reconstructed strata remain separate. No claim of accuracy, timing, token savings or tests already run.
