Noise goes. Failures stay.

Less for your agent to read, every turn.

Lean trims noisy shell output before your coding agent reads it and keeps every line that says what failed. It also measures what your MCP servers, rules and skills add to every turn. It is early: the numbers below come from one benchmark.

Current scope

The shell filter and the prefix audit ship in the default source build today. The filter has one benchmark, on this repository. The handoff prompt needs Footnote Memory. We have not measured what Lean saves on a real bill, and the rules that make an agent write less are an experiment, off by default.

How it works

  • Shell filter. footnote install --lean adds a hook to Claude Code, Codex and Antigravity CLI that routes noisy commands through footnote run: builds, tests, git, linters and search. Output that would not get smaller passes through untouched.
  • Nothing is lost. The full output is kept on your machine. footnote output <id> brings it back. Output that looks like a credential is never stored.
  • Prefix audit. footnote audit-prefix --probe-mcp measures the tool schemas of each MCP server, your instruction files and your skill headers: what every turn carries before you type. It only reads, and prints no contents or secrets.
  • Handoff. With Footnote Memory, a session past 140,000 tokens, or resumed after 55 idle minutes with more than 60,000 tokens in context (the prompt cache has gone cold), is asked to save a one-paragraph handoff so you can start fresh without losing the thread.

What we measured

13 cases in 6 command families, 20 Nov 2026, on this repository. The bar was written before the run: keep at least 99 % of the lines that say what failed, save at least 20 % of the bytes, never make output bigger. Every family passed.

Not measured yet

  • What Lean saves on a real bill, end to end. That run is open; until it lands we make no claim about cost.
  • Prefix audit numbers across many real setups. Run it on yours and you will see your own.
  • The rules that make an agent write less (Lean B). A pilot of 6 runs per setup cut output tokens by 20 to 25 % at the same pass rate, too few runs to call a saving. Off by default.
