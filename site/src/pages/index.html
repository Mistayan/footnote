The Launcher: one small window for all four.

A desktop window with a tray icon. Switch a product on or off, search Library, Memory and Code at once, see your projects and models, and check how many tokens your agents used and Lean saved.

  • Windows only for now. Linux and macOS builds are not done.
  • No installer yet. You build it from source, next to the command line tool.
  • It does little. It runs a short list of read commands, a product's switch and a model install. Nothing else.

Three steps, from source.

There is no installer and no prebuilt download yet; this is the developer path. You need Rust 1.92 or later and about 200 MB of disk for the two default embedding models (Python 3.10+ is optional, only for PDF/Office extraction).

1 · Build

One Rust binary. Put target/release on your PATH.

git clone https://github.com/bobcat88/footnote cd footnote cargo build --release

2 · Models

A one-time native download of two small public models, verified by SHA-256.

footnote models install bekko-a8m footnote models install gte-small

3 · Connect

Sets up Memory, its hooks and /remember in every supported agent it finds.

footnote install --memory

Update with footnote update --from <binary>, go back with footnote rollback, remove the hooks with footnote uninstall --memory. Your data stays in its own folder. Something failed? Open an issue on GitHub or write to johan.velocity.lab@pm.me.
